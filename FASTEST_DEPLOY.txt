STEP 1: GitHub Setup (3 minutes)
═════════════════════════════════════════════════════════════════════════

Run these commands (copy & paste):

git init
git add .
git commit -m "Fake call backend"

Go to: https://github.com/new
- Repository name: fake-call-backend
- Click "Create repository"
- Copy the commands shown

Paste into terminal:
git remote add origin https://github.com/YOUR_USERNAME/fake-call-backend.git
git branch -M main
git push -u origin main

✅ Your code is on GitHub!

═════════════════════════════════════════════════════════════════════════
STEP 2: Create Railway Account (2 minutes)
═════════════════════════════════════════════════════════════════════════

1. Go to: https://railway.app
2. Click "Start Project"
3. Click "Deploy from GitHub"
4. Authorize Railway to access GitHub
5. Select your "fake-call-backend" repository
6. Click "Deploy Now"

✅ Deployment started!

═════════════════════════════════════════════════════════════════════════
STEP 3: Add MongoDB Database (2 minutes)
═════════════════════════════════════════════════════════════════════════

1. In Railway dashboard
2. Click "Create" → "Database" → "MongoDB"
3. Railway automatically adds MONGODB_URI to your app!

✅ Database connected!

═════════════════════════════════════════════════════════════════════════
STEP 4: Get Your Live URL (1 minute)
═════════════════════════════════════════════════════════════════════════

1. Go to Railway dashboard
2. Click your project
3. Go to "Settings" tab
4. Find "Domains"
5. Your URL: https://your-project.up.railway.app

✅ Your backend is LIVE!

═════════════════════════════════════════════════════════════════════════
STEP 5: Test It (1 minute)
═════════════════════════════════════════════════════════════════════════

Open terminal and run:

curl https://your-project.up.railway.app/health

If you see:
{"status":"OK","timestamp":"2026-10-14T..."}

✅ Everything works!

═════════════════════════════════════════════════════════════════════════
STEP 6: Connect Your Android App (1 minute)
═════════════════════════════════════════════════════════════════════════

In your Android app code:

Change:
API_BASE_URL = "https://your-project.up.railway.app"

Rebuild and test!

✅ Done!

═════════════════════════════════════════════════════════════════════════
🆘 IF DEPLOYMENT FAILS
═════════════════════════════════════════════════════════════════════════

Check Railway logs:
1. Go to Railway dashboard
2. Click your project
3. Click "Logs" tab
4. Look for errors

Common issues:
- "PORT already in use" → Railway handles this, ignore
- "MONGODB_URI not set" → Railway adds it, just wait
- "Node version error" → Railway uses latest Node

If stuck:
- Check logs first
- Wait 5 minutes (deployment takes time)
- Try redeploying: Railway dashboard → Redeploy
